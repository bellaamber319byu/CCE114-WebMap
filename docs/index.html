About This Map

USA Natural Hidden Gems is an interactive map designed to highlight the geographic diversity and natural attractions found throughout the United States.

The map includes four natural feature datasets: unique landscapes, water features, mountain features, and national parks. It also includes state boundaries to help users understand where each feature is located.

Users can turn layers on and off, search for locations, zoom in on geographic features, and select individual features to explore their available information. The purpose of this project is to encourage exploration and appreciation of America's natural beauty.

AI Statement

I used ChatGPT to improve the design, organization, and code for my USA Natural Hidden Gems map. The main technologies are HTML, CSS, and JavaScript, along with the Leaflet mapping library. The map uses OpenStreetMap for its basemap and GeoJSON files for its geographic layers.

Three helpful prompts were: “Help me make the map look more like my reference example,” “Add an About This Map section that explains the project,” and “Update the code so the map is titled USA Natural Hidden Gems and includes a clear legend.” These prompts helped improve the map's appearance, organization, and usability.

One problem I encountered was that an earlier code update caused the USA state outline layer to disappear. I noticed the missing outlines when I checked the map after the update. I explained the problem and had the code revised so the state boundary layer would load and display again. I then checked the map to make sure the outlines were visible.

I personally reviewed the finished website instead of assuming the AI-generated code was correct. I tested the layer checkboxes, searched for locations, clicked map features to view their information, checked that the legend colors matched the layers, and used the reset button. I also checked that the map title, About This Map section, AI statement, and OpenStreetMap attribution appeared. AI helped me with coding and design, but I reviewed the final result and tested the main features before submitting the project and that each section was clear and readable for visitors.
