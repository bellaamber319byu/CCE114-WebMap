About This Map

This interactive map highlights some of Utah's natural attractions and geographic features. It includes four different map layers: unique landscapes, water features, mountain features, and national parks.

Use the checkboxes to turn map layers on and off, search for a location by name, or click a feature to view its information. The goal of this project is to encourage exploration and appreciation of Utah's diverse natural landscapes.

AI Note

I used AI as a tool to help improve the design and organization of my interactive map. Some prompts I used included asking how to make the map look more like my reference example, how to add an About This Map section, and how to include an AI note.

AI also helped me work through the HTML and JavaScript structure. One thing I checked was that the OpenStreetMap attribution was included for the basemap. I reviewed the map layers, search feature, location information, legend, and reset button as part of checking my project.
